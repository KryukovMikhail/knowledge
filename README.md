# Путешествие в страну знаний

Познавательная игра для школьников: выбор класса → карта предметов → главы учебника → квесты с заданиями.

Играть: https://kryukovmikhail.github.io/knowledge/

Технический стек и устройство проекта — в [ARCHITECTURE.md](ARCHITECTURE.md).

Сейчас открыт **6 класс → История** (учебник «Всеобщая история. История Средних веков», Мединский, Чубарьян):
- Глава I. Европа в Раннее Средневековье (§ 1–4)
- Глава II. Мусульманская цивилизация в VII–XI вв. (§ 5–6)
- Глава III. Средневековое европейское общество — «Часть 1» и «Часть 2»
- Глава IV. Расцвет Средневековья в Западной Европе (§ 10–14)
- Глава V. Страны и народы Азии, Африки и Америки в Средние века (§ 15–20)
- Глава VI. Осень Средневековья (§ 21–24)
- В конце пути — Замок знаний: итоговое испытание (30 случайных вопросов из всех глав)

Результаты: кнопка «📊 Мои результаты» на главной странице. Журнал попыток хранится только на устройстве игрока; отчёт можно отправить в мессенджер.

### Дополнительно (K001.008)
- **Загадки главы** в каждой главе: контурная карта (+ маршрут крестоносцев), кроссворд, «найди лишнее», «кто это говорит», «найди ошибку летописца». Открываются после квеста главы.
- **Работа над ошибками**: вопросы с ошибками возвращаются сегодня, через 1, 3 и 7 дней.
- **Вопрос дня** и серия дней 🔥.
- **Лента времени** 476–1492 и тренировка «поставь событие на ленту».
- **Герой**: звания от крестьянина до короля за звёзды.
- **Коллекция карточек** исторических личностей.
- **Озвучка** «Свитков знаний» (кнопка «Послушать»).

### K001.009
- **Приложение (PWA)**: кнопка «📲 Установить» на главной, иконка с совой, работа без интернета (`manifest.webmanifest`, `sw.js`). При релизе менять `VERSION` в `sw.js` вместе с `BUILD`.
- **Перенос прогресса**: «💾 Перенос прогресса» — сохранить в файл или в код и загрузить на другом устройстве.
- **Грамоты**: «🏅 Мои грамоты» в «Моих результатах», грамоту можно сохранить картинкой или распечатать.

### K001.012
- **Пятибалльная оценка**: после каждого испытания выводится оценка 5/4/3/2 по доле правильных ответов (≥90% — «5», ≥75% — «4», ≥50% — «3», иначе «2»), процент и число ошибок. Звёзды теперь выводятся из оценки (5 → ★★★, 4 → ★★, 3 и 2 → ★).
- «Мои результаты»: **средний балл из 5**, оценка у каждой попытки и в отчёте для родителей (старые попытки пересчитываются по числу ошибок).
- **Больше заданий**: в каждое из 86 основных испытаний добавлено по 4–5 новых вопросов (всего +345), итоговые испытания — 30 вопросов вместо 20, «Вопрос дня» — 7 вопросов вместо 5.
