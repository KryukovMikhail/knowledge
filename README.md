# Результаты прохождения

Эту ветку заполняет сама игра «Путешествие в страну знаний».
Каждое устройство пишет свой файл `results/<id устройства>.json` с журналом попыток.
Смотреть результаты удобнее в игре: Кабинет администратора → «Все устройства».

Ветка отделена от `main`, поэтому запись результатов не пересобирает сайт.
