# Путешествие в страну знаний

Познавательная игра для школьников: выбор класса → карта предметов → главы учебника → квесты с заданиями.

Играть: https://kryukovmikhail.github.io/knowledge/

Сейчас открыт **6 класс → История** (учебник «Всеобщая история. История Средних веков», Мединский, Чубарьян):
- Глава I. Европа в Раннее Средневековье (§ 1–4)
- Глава II. Мусульманская цивилизация в VII–XI вв. (§ 5–6)
- Глава III. Средневековое европейское общество — «Часть 1» и «Часть 2»
- Глава IV. Расцвет Средневековья в Западной Европе (§ 10–14)
- Глава V. Страны и народы Азии, Африки и Америки в Средние века (§ 15–20)
- Глава VI. Осень Средневековья (§ 21–24)
- В конце пути — Замок знаний: итоговое испытание (20 случайных вопросов из всех глав)

Кабинет администратора: 5 раз нажать на номер сборки в левом нижнем углу главной страницы, затем ввести PIN.

## Сохранение результатов в GitHub

Игра пишет журнал попыток в ветку `results` этого репозитория (`results/<id устройства>.json`). Ветка отдельная, поэтому сайт при этом не пересобирается.

Настройка (один раз на устройстве ребёнка): кабинет администратора → «Сохранение в GitHub» → вставить fine-grained токен с доступом только к репозиторию `knowledge` и правом **Contents: Read and write**.

Смотреть результаты можно с любого устройства: кабинет администратора → «☁️ Все устройства» (токен для чтения не нужен).
