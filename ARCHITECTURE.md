# Технический стек и устройство

«Путешествие в страну знаний» — статический сайт без сервера и сборки: одна HTML-страница с встроенными стилями и скриптом, которая публикуется через GitHub Pages и устанавливается как приложение (PWA).

## Коротко

| Слой | Что используется |
|---|---|
| Разметка и логика | HTML5 + чистый JavaScript (ES2020+), без фреймворков и библиотек |
| Стили | CSS3 (переменные, grid/flex, анимации, `@media print`), встроены в `index.html` |
| Графика | Встроенный SVG (карты глав, контурные карты, замки, герой) и эмодзи; Canvas 2D — только для грамоты-картинки |
| Шрифты | Google Fonts: Philosopher (заголовки), PT Sans (текст) |
| Звук и озвучка | Web Audio API (звуковые эффекты синтезируются кодом), Web Speech API (`speechSynthesis` — чтение уроков вслух) |
| Хранение данных | `localStorage` браузера (прогресс, журнал попыток, настройки) |
| Офлайн и установка | Web App Manifest + Service Worker (`sw.js`) |
| Хостинг | GitHub Pages из ветки `main`, корень репозитория |
| Сборка, бэкенд, база данных | Нет |

## Файлы репозитория

| Файл | Назначение |
|---|---|
| `index.html` | Вся игра: разметка, CSS, JavaScript и учебный контент (~560 КБ, ~3600 строк) |
| `sw.js` | Service worker: кэш для работы без интернета |
| `manifest.webmanifest` | Описание PWA: название, иконки, цвета, полноэкранный режим |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` | Иконки приложения |
| `README.md` | Описание игры и список изменений по версиям |
| `ARCHITECTURE.md` | Этот документ |

## Устройство `index.html`

Внутри один блок `<style>` и один `<script>`. Скрипт делится на крупные части:

1. **Утилиты и экраны.** Функции `screen()` и `modal()` перерисовывают содержимое страницы через `innerHTML`. Маршрутизатора нет: каждый экран — отдельная функция (`classes()`, `world()`, `historyMap()`, `questMap()`, `resultsScreen()` и т. д.).
2. **Контент** — данные в виде JS-объектов:
   - `QUESTS` — квесты (главы и темы) с полями `id`, `sub` (предмет: `w` — Всеобщая история, `r` — История России, `g` — География), `stations` (испытания), `reward` и др.;
   - испытание (station) — урок совы (`lesson`, HTML) и массив заданий `tasks`;
   - `CHAPTERS`, `RCHAPTERS`, `GCHAPTERS` — порядок глав и тем на карте предмета;
   - `SUBJ` — настройки острова-предмета: название, замок итогового испытания, палитра;
   - `CARDS`, `EVENTS`, `MAPS`, `RANKS` — коллекция карточек, лента времени, контурные карты (координаты береговых линий и рек), звания героя;
   - `EXTRA` — дополнительные вопросы, которые при запуске добавляются в испытания.
3. **Движок заданий** — по функции на тип: `quiz`, `tf` (правда/ложь), `fill` (пропущенное слово), `odd` (лишнее), `who` (кто говорит), `sort` (по корзинам), `match` (пары), `order` (порядок), `map` (контурная карта и маршрут), `cross` (кроссворд генерируется кодом), `mistake` (ошибка летописца), `timeline` (лента времени). Вопросы и варианты ответов при каждом прохождении перемешиваются. Первый вариант в данных — всегда правильный.
4. **Оценивание.** `finish()` считает долю правильных ответов: ошибки делятся на число «единиц» заданий (`taskUnits`), а `gradeOf()` выставляет оценку от 2 до 5 (≥90% — «5», ≥75% — «4», ≥50% — «3»). Звёзды выводятся из оценки.
5. **Генераторы.** Итоговые испытания (`genFinal` — 30 случайных вопросов по предмету), «Вопрос дня» (`genDaily` — 7 вопросов, выбор зависит от даты), «Работа над ошибками» (`genReview` — интервальное повторение: сегодня, через 1, 3 и 7 дней).
6. **Игровые системы.** Герой и звания, коллекция карточек, серия дней, дуэль с родителем (поочерёдные ответы на время), грамоты, перенос прогресса.

Каждый вопрос получает стабильный ключ `станция:задание:вопрос` (`buildIndex()`). На этих ключах держатся повторение ошибок и вопрос дня.

### Объём контента (K001.012)

- 3 предмета, 29 квестов (включая «Загадки глав»), 100 испытаний, 292 задания, ~1300 вопросов и элементов заданий;
- 72 карточки в коллекции, 59 событий на лентах времени;
- 3 итоговых испытания (Замок знаний, Кремль знаний, Обсерватория знаний).

## Данные игрока

Все данные хранятся только в браузере игрока, на сервер ничего не уходит.

| Ключ `localStorage` | Что хранит |
|---|---|
| `pvsz_v1` | Сохранение: имя, звёзды по испытаниям, открытые квесты, карточки, звание, очередь повторения ошибок, серия «Вопроса дня», статистика дуэлей |
| `pvsz_log` | Журнал попыток (до 800 записей): дата, испытание, оценка, процент, ошибки, время, тексты ошибок |
| `pvsz_sound` | Включён ли звук |

**Перенос прогресса.** Сохранение можно выгрузить в JSON-файл или в текстовый код: JSON сжимается через `CompressionStream` и кодируется в base64. На другом устройстве его загружают обратно.

**Отчёт родителям** собирается как текст и отправляется через `navigator.share`. Если это недоступно, текст копируется в буфер обмена.

**Грамота** рисуется на `<canvas>` и сохраняется в PNG (`toBlob`), а для печати есть отдельные стили `@media print`.

## PWA и офлайн

- `manifest.webmanifest` позволяет установить игру на главный экран телефона. На Android кнопка «📲 Установить» использует событие `beforeinstallprompt`, на iOS показывается подсказка.
- `sw.js` при установке кэширует оболочку (страница, манифест, иконки):
  - страница — «сначала сеть, потом кэш»: обновления приходят сразу, без интернета открывается сохранённая версия;
  - иконки и шрифты Google — «сначала кэш».
- Старые кэши удаляются при смене версии.

## Версии и выпуск

- Номер сборки — константа `BUILD` в `index.html` (формат `K001.NNN`, показывается в левом нижнем углу главной страницы) и `VERSION` в `sw.js`. **Их нужно менять вместе**, иначе установленное приложение не обновит кэш.
- Изменения по версиям описаны в `README.md`.
- Выпуск — коммит в `main`. GitHub Pages публикует сайт автоматически за 1–2 минуты.

## Проверка

Автотестов в репозитории нет. Перед выпуском:

- синтаксис скрипта проверяется через `node --check` на скрипте, вынутом из `index.html`;
- сценарии проходятся headless-браузером (Playwright + Chromium): бот проходит все испытания всех предметов с правильными и случайными ошибочными ответами, проверяет отсутствие ошибок JavaScript и делает скриншоты экранов в мобильном разрешении (390×844).

## Поддержка браузеров

Современные Chrome, Safari (iOS 15+), Edge, Firefox; вёрстка рассчитана в первую очередь на телефон. Если браузер не поддерживает какое-то API, игра всё равно работает:

- нет `speechSynthesis` — кнопка «Послушать» показывает подсказку, что браузер не умеет читать вслух;
- нет `CompressionStream` — код переноса не сжимается;
- нет Service Worker — игра работает только онлайн.
